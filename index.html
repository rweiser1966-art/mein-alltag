Einstellungen & Daten

Synchronisierung zwischen iPhone und MacBook

Noch nicht eingerichtet. Deine Daten werden vorerst in diesem Browser gespeichert.

Für eine echte Synchronisierung wird ein gemeinsamer Cloud-Datenspeicher benötigt. Diese Version unterstützt Supabase mit persönlicher Anmeldung per E-Mail-Link. Richte ein Supabase-Projekt ein und trage die Projekt-URL sowie den öffentlichen anon/publishable key ein.

Der öffentliche Key ist für die Client-Nutzung vorgesehen. Sicherheit hängt von aktivierten Row Level Security-Regeln ab – verwende niemals einen service_role-Key in dieser App.

Datensicherung

Exportiere eine Sicherung als JSON, um deine Daten zu sichern oder auf ein anderes Gerät zu übertragen. Beim Import werden die Einträge zusammengeführt.

Startwerte

Die App übernimmt nur Messwerte, deren Datum bekannt ist. Unvollständig datierte Zwischenwerte aus früheren Aufzeichnungen werden nicht erfunden.
